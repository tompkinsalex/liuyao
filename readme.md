# 六爻模拟器

基于python实现的六爻铜钱卦模拟程序，完成摇卦和装卦后，将这些交给大模型去解答

- `liuyao_roller.py`：只负责摇卦，输出原始爻列表（如 `['少阴','少阳','老阳','少阴','少阴','少阳']`）
- `zhuanggua.py`：接收该列表，负责查表、装卦、排地支六亲等，输出结构化的卦象数据（如本卦名、变卦名、世应位置、六亲、六神等）
- `explainer_with_llm.py`：调用 `zhuanggua` 得到结构化数据，再结合用户问题调用大模型生成解读
- `/data/...`：装卦对应的静态数据表
- `config.py`：放一些提示词，配置信息

## 摇卦

1. 获取当日时间，通过万年历找到当天的日月天干地支，看空的是什么。

2. 抛古钱币，提供了程序模拟和手动输入两种方式，推荐后者。

## 装卦

这部分由程序静态推演得出，

1. **本卦生成**（已有六次结果，少阳、少阴、老阳、老阴，自下而上）。
2. **变卦生成**：动爻（老阳变少阴，老阴变少阳）得到变卦。
3. **识别本卦信息**：
   - 上卦、下卦 → 确定卦名（如䷸ 巽为风）
   - 所属八宫（如巽宫）→ 宫位五行（巽属木）
   - 是否六冲卦（如巽为风是六冲）
   - 世爻、应爻位置（查表或口诀）
4. **本卦装地支**：每爻配一个地支（子丑寅卯…），规则分内外卦、阳卦阴卦等（查表为主）。
5. **本卦装六亲**：以宫位五行为“我”，每爻地支的五行与“我”生克关系定六亲（父母、兄弟、妻财、官鬼、子孙）。
6. **变卦处理**：
   - 变卦的地支（独立重新装，与主卦规则相同）
   - 变卦的六亲：仍然以**本卦的宫位五行**为“我”来配（不变宫）
   - 变卦不单独定世应、宫位、六冲（一般只写变卦卦名）
7. **空亡**：根据起卦时的日辰地支，推算旬空（如甲子旬戌亥空），标记主卦中哪些爻的地支逢空。
8. **六神**：根据日干（甲乙起青龙…）从初爻到上爻依次排定。
9. **神煞**（可选）：如驿马、桃花、贵人等，根据日支或年支计算。


## 解读

得到本卦、变卦及详细信息后，将query和上述信息交给大模型解读，返回解读结果。
